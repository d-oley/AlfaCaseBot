## Название проекта

AlfaCaseBot - учебный тренажёр для работы с бизнес-кейсами. Пользователь читает условие, предлагает решение и получает оценку с коротким отзывом. Результаты и отправленные попытки сохраняются в личном кабинете.

Проект подготовлен по теме кейса 5 «Alfa-ИВР». AlfaCaseBot не является официальным продуктом Альфа-Банка.

## Проблема

Решать бизнес-кейсы по одним только теоретическим материалам трудно: полезно попробовать свой вариант, увидеть результат и вернуться к задаче. Проверка развёрнутого ответа вручную требует времени. В AlfaCaseBot можно отправить несколько вариантов решения и сравнить свои результаты.

Оценка помогает продолжить работу над ответом, но не заменяет проверку преподавателем или экспертом. Автоматический отзыв может ошибаться, особенно при проверке фактов и нестандартных решений.

## Аудитория

Проект рассчитан на школьников, студентов и других людей, которые хотят практиковаться в разборе бизнес-задач. Для преподавателя он может быть вспомогательным инструментом, но отдельный кабинет преподавателя в текущем интерфейсе не заявлен. Доступ работодателей к истории решений и «скилл-паспорт» в проекте не реализованы.

## Что доступно пользователю

- Регистрация и вход с подтверждением аккаунта по почте или через Telegram.
- Каталог кейсов с фильтрами по теме и сложности. Кейс можно добавить в избранное и оценить по пятизвёздочной шкале.
- Условие кейса на сайте и PDF с полным условием, если файл добавлен.
- Чат для отправки решений. После каждой попытки пользователь видит оценку от 0 до 100 и короткий отзыв. Пока кейс не завершён, можно отправлять новые варианты.
- Завершение кейса вручную. После завершения продолжить чат по этому кейсу нельзя. Эталонное решение можно открыть после завершения, если оно добавлено.
- Теория и тесты по кейсам. Материалы доступны независимо от полученного балла; успешный результат теста начинается с 70%.
- Личный кабинет с попытками, лучшими результатами, избранным, достижениями и местом в рейтинге. Рекомендация кейса учитывает выбранные пользователем тему и сложность.

Для администратора в интерфейсе предусмотрены работа с кейсами, теорией, пользователями, решениями и тегами. Права проверяются сервером Java.

## Как работает оценка

Перед оценкой сообщение проходит проверку на токсичность. Сервис оценки использует пять критериев: факты, оригинальность, эффективность, логика и полнота. Их веса в итоговом балле - 20%, 25%, 25%, 15% и 15% соответственно.

В смешанном режиме RuBERT Tiny2 локально оценивает эффективность, логику и полноту. OpenRouter используется для проверки фактов, сравнения с эталоном по оригинальности и составления итогового отзыва. Отзыв не должен раскрывать эталон или давать готовое решение. В коде есть также режим, где все пять критериев оцениваются через OpenRouter.

Пользовательский интерфейс показывает итоговый балл и отзыв. Отдельные баллы по пяти критериям в чате сейчас не выводятся.

## Технологии и запуск

- Сайт: Vue 3, JavaScript, CSS.
- Сервис оценки: Python, FastAPI, модель RuBERT Tiny2, модель проверки токсичности и запросы к OpenRouter.
- Отдельный Java-сервер отвечает за аккаунты, кейсы и сохранение результатов.
- Docker Compose в каталоге code запускает сайт и смешанный сервис оценки. Java и хранилище файлов запускаются отдельно.

Пользователю нужен браузер с включённым JavaScript и подключение к интернету. Точная минимальная скорость соединения и список официально поддерживаемых браузеров не установлены.

## Текущее состояние и следующие шаги

Сайт, административные страницы и оба варианта сервиса оценки есть в исходниках. Проверки кода и сборка выполнялись локально. Полная работа всех сервисов вместе и пользовательский пилот этим не подтверждены.

Перед пилотом нужно проверить регистрацию, отправку решений, сохранение результатов и доступ администратора на запущенных сервисах. Для смешанного режима на сервер отдельно передаются веса RuBERT Tiny2: они не хранятся в Git

## Риски

- Автоматическая оценка может неверно понять решение или факт. Для выводов о качестве модели нужна отдельная проверка на размеченных ответах.
- Работа сайта с настоящими данными зависит от доступности Java-сервера и сервиса оценки.
- Смешанный режим не запустится без совместимых весов RuBERT Tiny2 и нужных ключей для внешних запросов.
- Проверка токсичности может ошибочно отклонить допустимый текст или пропустить нежелательный
